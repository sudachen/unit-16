Lab-16 is a project to create a literary matrix, an automatic generator of science fiction stories in the language and setting of a chosen author based on an arbitrary description of the desired work.

This is a research project whose goal is to investigate the possibility of extracting literary DNA and building on it high-quality unique texts with the literary code of a chosen author.

A distinctive feature is that everything, from training to text generation, is done on local LLMs and affordable consumer hardware of the Ryzen 9 + RTX 5060 Ti class.

``` bash
git clone https://github.com/sudachen/lab16_rs.git
cd lab16_rs
git submodule update --init --recursive
```
